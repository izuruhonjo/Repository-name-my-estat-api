## 結論（3行）
1. **記事の70.6億円は再現できない。** 記事の全条件（疑似3倍・税20.315%・コストなし）でも **25.0億円**（2022/8時点）。非課税にしても60.7億円で、記事値に届かない。部品（ツミレバ3.60億 vs 記事3.59億、初回買い1989/4）は一致しており、記事本体の数値に誤りがあるとみられる。
2. **現実のコストを入れると、資産は記事条件の約1/4になる。** 特に効くのは「3倍の借入コスト（−72%）」と「約定の1日遅れ（−31%）」。SBIの手数料（−1%）と為替手数料（ほぼ0）は誤差の範囲。
3. **優位は1990年代が作ったもの。** 積立開始を2000年以降にすると、QQQMの単純積立とほぼ同じで、TQQQの単純積立には大きく負ける。最大ドローダウンはどの開始年でも−58〜−83%で、「暴落を避ける」という記事の主張は数字では裏付けられない。

## ケースの定義
- **A**: 記事どおり（価格指数の日次騰落率×3、売却ごとに利益へ20.315%課税、月末終値で約定、円とドルの区別なし）
- **B**: A + 3倍の調達コスト（2×米短期金利）+ 配当込み + 経費率等。経費率等は実TQQQに合わせて**年1.92%に較正**（トラッキング誤差は年3.8%）。翌営業日に約定。
- **C**: B + SBI手数料0.495%（上限22USD）+ スリッページ0.02% + 為替（円建て）+ 特定口座（年内の損益通算と3年繰越）+ 配当課税28.28%

## 改良案のアウトオブサンプル検証（2026-11-06 追加）
対象: ①「金利が高い時期はレバレッジを2倍に下げる」 ②「月末の引けで約定する」。結果は `out/MPI_ver4_OOS検証.xlsx` と fig5〜7。

### 結論（3行）
1. **① 高金利で2倍：採用してよいが、効果は小さい「保険」。** 作成期間で選んだ規則（米3M金利が6%を超えたら2倍、毎月判定）は、使っていない期間・指数の全期間で一度も損をしなかった（0〜+18%。10年窓でもOOSの負けは1回だけ）。ただし効くのは金利が6%を超えた時期だけで、作成期間での改善（+16%）は41年間で乗換え2回だけから来ている。閾値を5%に下げると作成期間で−38%になり、結果が閾値で大きく変わる。
2. **② 月末引け約定：採用する根拠はない。** 作成期間(NDX)の+46%は、他の期間・指数では−5%〜+21%に縮み、符号もそろわない。10年窓ではS&P500 1950-85で6勝20敗。
3. **より重要な発見：ver4.0戦略そのものが「月末1日」の値動きに依存している。** 月末前日の終値で判定すると（実際に月末引けで約定できる方法）、NDXの最終資産は38.0億円→**4.9億円**になる。2000年9月の売りシグナル（ドットコム崩壊の回避）が、最終日の−4.1%でぎりぎり成立していたため。
   - **【2026-11-06 訂正】** 下の「シグナル摂動テスト」で、この結論は言い過ぎだったと分かった。4.9億円は「過去の月足は暦月、当月だけ1日短い足」という混在した作り方から生じた値。月足を**全期間そろえて**1日前に締めると78.1億円になり、締め日をどこにずらしてもドットコム崩壊は2000/9/25〜10/30に回避できる。

- ②は3方式：翌営業日引け（C、基準）／月末引け・当日終値で判定（C-MOC。厳密には実行不能）／月末引け・前日終値で判定（現実的MOC。実行可能）。

## シグナル摂動テスト（2026-11-06 追加）
目的: ver4.0 の結果が「月足の締め日」「約定日」「少数のシグナル」にどれだけ依存しているかを測る。結果は `out/MPI_ver4_摂動テスト.xlsx` と fig8〜10。

### 結論（3行）
1. **基準（月末締め）は「当たりの締め日」ではない。ただし結果の幅は非常に大きい。** 締め日を−10〜+10営業日ずらした21通りで、NDXの最終資産は12億〜134億円（11倍の幅）。基準の38.0億円は21通り中16位で、中央値は63億円。±1〜3日ずらした6通りは、すべて基準以上（39〜134億円）。
2. **優位はNDXだけ。** NDXでは21通り中20通りが3倍単純積立に、21通り全部が1倍単純積立に勝つ。しかし使っていない期間・別の指数（6セット×21通り＝126通り）では、**3倍単純積立に勝ったのは0通り**。1倍単純積立にも勝てない場合が多い（勝率0〜76%）。
3. **資産の大半は「ドットコム崩壊の回避」1回から来ている。** 2000/9の売り→2003/4の買いを消すと、38.0億円→1.3億円（−97%）。この回避は締め日をどこにずらしても起きる（26通りすべてで2000/9/25〜10/30に売り）ので、偶然の1日ではない。ただし退避12回のうち、得になったのは3回（2000年・2008年・2022年）だけで、残りの9回はダマシ（例: 2020/3のコロナ退避を消すと+119%）。

### 判定（事前に固定した基準）
| 判定 | 基準 | 結果 |
|---|---|---|
| A 位相頑健性（21通りの中央値÷基準） | 0.5以上で頑健 | NDX 1.66 → **頑健**（OOSは0.50〜1.23。ダウ0.496だけ境界） |
| B 対ベンチマーク（21通りで勝つ割合） | 80%以上 | NDX: 3倍積立に95%、1倍積立に100% → **合格**。OOS 6セット: 3倍積立に**全セット0%** → **不合格** |
| C 集中度（1組消して半分以下になるか） | なければ分散 | 4組あり（2000年退避−97%、1995-2000年保有−92%、2008年退避−59%、2012-15年保有−55%）→ **単一エピソード依存** |

### 検証の設計（結果を見る前に固定）
- 共通: 現実コストC、名目3万円/月、積立は月初。積立日・コスト・税は変えず、**シグナルだけを動かす**。
- P1 締め日シフト: 月足の締め日を「月末最終営業日＋k営業日」に変え、全期間の月足・MACD・パラボリックを作り直す（k=−10〜+10の21通り≒1か月の全位相）。シグナルは締め日の翌営業日の引けで約定。参考で暦日締め（5/10/15/20/25日）も計算。
- P2 約定遅延: シグナルは基準のまま、約定を締め日の0〜5営業日後に。
- P3 エピソード除去: NDXの基準シグナル25本のうち、連続する2本（保有1回または退避1回）を1組ずつ消す。
- 検証セットは前回のOOS検証と同じ7つ。21通りは隣どうしで月足の大半を共有するので独立ではない（割合は記述統計）。

### 実務上の示唆
- **月末引けで約定したいなら、月足を全期間「月末の1営業日前」で締めれば実行可能**（k=−1、NDXで78.1億円）。ただしこれは21通りの1つで、選んだ理由は「実行できること」だけにする。結果が良いから選ぶのは過剰最適化。
- 期待値の目安は「1つの締め日の値」ではなく**21通りの分布（NDXで12〜134億円、中央値63億円）**で持つべき。どの締め日を選んでも、結果は数倍ぶれる。
- この戦略の本質は「数十年に1度の大暴落（NDXで−80%級）から3倍を逃がす保険」。ダマシの方が多く、平時はコストになる。NDX以外の指数では3倍単純積立に一度も勝てなかったので、**ver4.0をNDX以外に使う根拠はない**。

### 検証（突合）
`python3 verify_perturb_excel.py`（LibreOfficeで再計算したExcelを読む）で全て一致：
- 「検算_締め日-7」「検算_締め日+3」: NDXの**日次の生データから数式だけで**、締め日をずらした月足→MACD→パラボリック(状態遷移を14列で再現)→売買シグナルを作り直す → Pythonとシグナル不一致0（29本・23本）、高値/安値/終値・パラボリックの差0
- 「検算_台帳-7」: 上の数式シグナルをそのまま使い、日次の売買台帳（税・手数料・為替なし）を数式で再計算 → Pythonとの最大乖離率 1×10⁻¹⁴（最終22億724万円で一致）
- 「概要」: 7セットの中央値・最小・最大・勝ち数を MEDIAN(IF)/COUNTIFS で再集計 → 差0
- 「P3エピソード除去」: 半分以下になる組数・対数比 → 差0（2×10⁻¹⁶）
- 回帰テスト: k=0 の月足・シグナルは既存の `monthly_bars` と完全一致（assert）。基準38.0億円を再現。
