## 3. 売買ルールを時系列で

やることは「メールを読む」と「切り替わった月だけ売買する」の2つ。計算はすべて自動メールがやる。下の①〜⑫は1か月の流れの順。評価の数字は「そのルールだけを外した場合」との差（K0エンジン・DCエンジンで再計算、Excel突合済み）。

| 趣旨 | 価格の揺れ（ボラ）が大きい時期は、下げが続きやすく、下げ幅も大きい。揺れの大きさだけで判断し、方向は当てに行かない |

| 急な上げ相場で置いていかれる | 2009年：世帯+16.4%対QQQ+57.3%、2023年：+44.8%対+65.6% | 暴落を避けた分で取り返す設計。7年で評価する |
| 円高を2倍で受ける（S2口座） | 2015〜16年の−36.1%、2024年8月 | 円で見る限り避けられない。為替ガードは検証で−4.7pt（不採用） |
| 月中の急落は逃げきれない | 2020年2〜3月 | ボラ・ブレーキが半分だけ守る |
| DCは遅れて動く | 売りから買いまで約1週間 | 遅れの影響は小さい（⑧の評価）。DCにはブレーキを入れない |
| 過去に合わせすぎている可能性 | 設計は2000〜2026年のデータ | 改良検証29通り・DC規則12通りで、偶然でない改善は見つからなかった＝今のルールが手堅い |

迷ったとき：①売りたくなったら月末まで待つ、②買い増したくなったらしない（余ったお金は生活防衛費へ）、③別の戦略が良く見えたら1月の年次チェックまで待つ、④成績が悪くて不安なら「ルールどおりに回せたか」だけを見る。

## 7. 前提・突合・再現

- 期間：2000年4月3日〜2026年10月30日（26.6年）、日次、円建て。S2口座は正典エンジンK0（`s2x.py` の `XCfg(keep_brake_on_switch=True)`）：譲渡益税20.315%と損失3年繰越、信託報酬、入金待ち6営業日、判定翌営業日に執行
- DC：`dc_engine.py` のR0（実際の基準価額25本。野村外国株式インデックスファンドは2002年2月より前を先進国株の指数で代用）、売りから買いまで4営業日、預金は6か月未満0%・以後年0.1%。日本の営業日の値を、米国の営業日にそろえた（その日以前の最新の基準価額）。DCの株フラグは判定から復元し、外国株を持つ日のリターンが野村外国株式インデックスファンドと一致することを確認（差2e-16）
- NISA：iFreeNEXT FANG+インデックス（信託報酬年0.78%）。2019-11-14より前はNASDAQ100（配当込み）で代用（控えめ）。ブレーキはQQQの20日ボラ30%で半分売り、翌営業日に執行、月末に30%未満なら翌営業日に戻す。年間枠の制約は入れていない
- QQQ持ちっぱなし：QQQの終値（配当なし）×為替、税なし。S2口座のNASDAQ100部分も配当なしの終値で計算しているので、条件はそろっている（配当分の年0.5〜1%程度は両方とも入っていない★）
- 世帯：11/6実額の構成比（S2口座80.6%・DC17.9%・NISA1.5%）を毎月末に戻す仮想の合成。積立は入れていない（年率をゆがめないため）
- 月次の指標（ベータ・相関・追随率・情報比・CVaR・勝ち月）はQQQとの月次リターンで計算。追随率は「QQQが上げた月（下げた月）の平均リターン÷QQQの平均リターン」
- **Excel突合 `総合マニュアル_Excel突合_2026-11-07.xlsx`：入力は各口座の日次の価値・株フラグ・MCの経路だけ。世帯の合成、20指標（7系列）、年次リターン、ルールを外した場合の年率と最大下落、MCの確率・中央値・口座別をすべて数式で再計算してPythonと照合。LibreOfficeで再計算し、237項目すべて一致**
- 再現：`cd S2_TQQQブリッジ枠検証_code && python3 tm_calc.py && python3 tm_excel.py && (cd out_tm && soffice --headless --calc --convert-to xlsx --outdir recalc 総合マニュアル_Excel突合.xlsx) && python3 tm_verify_excel.py > out_tm/excel_verify_log.txt && python3 tm_report.py`
- 将来の成績は過去と同じにはならない。数字は「過去と同じような相場が来たら」の目安

## 8. 用語

| 用語 | 意味 |
| --- | --- |
| ○／× | QQQの月末終値で決まる「攻める」「逃げる」の判定 |
| 通常／押し目／退避 | ○で高値比−10%以内／○でそれより深い／× |
| K0 | 正典エンジン。今のマニュアルどおりに動かしたS2（ブレーキ中の持ち替えは半分のまま） |
| R0 | DCのルール（○は野村外国株式インデックスファンド、×はりそな定期預金フリーポケット）。旧名DC④ |
| ボラ・ブレーキ | QQQの20日ボラが30%以上で半分を円にする保険。S2口座とNISAに使い、DCには使わない |
| 守り待避 | ×の間の置き場。XLU50%＋IEF50%か円現金 |
| 換金後 | 今すべて売ったら手元に残る額（評価額−含み益の税） |
| 世帯 | S2口座＋DC＋NISAの合計（現金・自宅は含めない） |
| ソルティノ | 年率÷下落日の揺れ。下げ1単位あたりの稼ぎ（高いほど良い） |
| CVaR95 | 悪いほう5%の月の平均の下げ |
| ベータ／相関 | QQQに対する動きの大きさ／動きのそろい方 |
| 追随率 | QQQが上げた月・下げた月に、平均で何割ついていったか。上昇は高く、下落は低いほど良い |
| 情報比 | QQQに勝った分の平均÷その勝ち負けのぶれ |
| 中央値 | 10万本の未来を並べたときちょうど真ん中の値 |
